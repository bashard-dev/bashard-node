# Roadmap and project status

## Available source

- BSC coordination contracts and deployment metadata.
- Shared erasure coding, Merkle commitments and TypeScript SDK.
- Landing website, storage UI, network explorer and protocol guides.
- Read-only event indexer, disk node and cloud-backed custody service.

## Bootstrap validation

On-chain registration, stake and initial committee activation are complete.
End-to-end custody validation and public always-on hosting readiness must be
tracked independently. Do not treat a repository release as an availability
announcement or a third-party audit.

## Next priorities

- Public endpoint and durable-storage recovery validation.
- Operational monitoring and explicitly budgeted keeper automation.
- Independent-host operators and failure-domain testing.
- Protocol review, dependency maintenance and reproducible releases.

Dates and delivery commitments are intentionally not promised.
